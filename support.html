English

Support

If you found a bug, have a question, or need help using Beton Studio, you can contact us through the channel below.

Contact

Email: feher.robert@gmail.com

What we can help with

  • bug reports and technical problems
  • questions about app features
  • feedback about calculations that seem inaccurate
  • App Store, device, or compatibility problems

Useful details when reporting an issue

  • device type and operating system
  • which calculation module had the problem
  • a short description of the steps you took
  • if possible, a screenshot or exact error message

Response time

We aim to respond to all requests as quickly as possible.
